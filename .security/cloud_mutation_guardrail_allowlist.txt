# Regra de uso:
# - Use apenas quando estritamente necessario.

^backend/app/domains/cloud_accounts/service\.py$::delete_::Exclusao de metadados internos da conta integrada

^backend/app/domains/dev/service\.py$::scale::Texto de seed/demo sem chamada mutativa cloud
