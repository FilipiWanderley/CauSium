# Screenshots - Baseline 2026-06-11

## Objetivo

Armazenar screenshots do estado atual do CauSium para comparação futura.

## Como Capturar

1. Acessar https://app.causiumtech.com
2. Fazer login com credenciais válidas
3. Navegar para cada página listada abaixo
4. Capturar screenshot em resolução 1920x1080
5. Salvar em formato PNG
6. Nomear seguindo o padrão: `pagina-YYYY-MM-DD.png`
